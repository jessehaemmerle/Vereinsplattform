Anleitung, um im Docker-Container die App zum Laufen zu bringen:
Mittels Befehl "git clone https://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@github.com/jessehaemmerle/Vereinsplattform.git" das Repo klonen. 
Anschließend in den "Vereinsplattform" Ordner wechseln
Manuell die Ordner "databases" und "uploads" erstellen, diese werden nicht vom Clone-Befehl kopiert.
Danach mittels Befehl "sudo docker buildx build -t vereinsplanung_neu_v2 ." den Docker-Container erstellen

Wenn der Container erstellt ist kann mit dem Befehl "sudo docker run -d -p 80:5000 --name Vereinsplanung vereinsplanung_neu_v2" der Container gestartet werden.

Standard-Admin:
In der .env koennen DEFAULT_ADMIN_EMAIL, DEFAULT_ADMIN_USERNAME und DEFAULT_ADMIN_PASSWORD gesetzt werden.
Beim Start wird dieser Benutzer automatisch als system_admin erstellt oder aktualisiert. Nach dem Login kann
im Admin-Bereich ein eigener Vereins-Admin inklusive Verein erstellt werden.
Dieser neue Vereins-Admin bekommt einen Passwort-Link und legt das Passwort selbst fest. Beim Erstellen des
Vereins wird keine Lizenz mehr automatisch erstellt; Lizenzen werden separat erzeugt und zugewiesen.
